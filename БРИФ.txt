БРИФ: Разработка семантического HTML-скелета (без стилей)
1. Общая информацияПродукт: Сервис по подбору и бронированию эко-отелей «Зелёный Побег».Тип страницы: Главная страница сервиса (Main/Home page).
Зачем это нужно: Наш дизайнер еще дорабатывает UI-кит, но бэкендеры уже готовы натягивать структуру на движок. Мне нужен эталонный HTML-код, который идеально прочитают поисковые роботы и скринридеры.


2. Контентная структура страницы (сверху вниз)Макетов нет, ориентируйся на этот текстовый план:Шапка: Логотип компании, текстовый слоган, меню навигации (4 ссылки), кнопка «Войти в профиль».Первый экран: Главный заголовок, краткое описание сервиса, форма быстрого поиска (город, дата заезда, дата выезда, количество гостей, кнопка «Найти»).Популярные направления: Заголовок секции, список из 6 карточек направлений. Каждая карточка: название города, мини-описание, картинка, ссылка «Смотреть отели».Преимущества: Заголовок секции, список из 3 карточек (иконка/картинка + заголовок + текст).Секция со статьей: Интересный SEO-текст про эко-туризм (заголовок, 3 абзаца текста, одна цитата эксперта).Подвал: Копирайт, ссылки на соцсети (списком), ссылки на юридические документы (Политика конфиденциальности и т.д.).

3. Строгие технические требованияСемантика: Максимальное использование тегов HTML5 (<header>, <nav>, <main>, <section>, <article>, <aside>, <footer>). Никаких «диватозов» (десятков вложенных <div>).
Заголовки: Строгая иерархия. Один <h1> на странице. Все остальные секции — <h2>. Подзаголовки внутри карточек — <h3>. Никаких пропусков уровней.Стили: Полное табу. 
В коде не должно быть ни одного тега <style>, ни одного атрибута style="", ни одной ссылки на CSS-файл. На выходе я хочу видеть стандартную черно-белую страницу со стандартными шрифтами браузера.
Классы: А вот классы нужны! Разметь всю структуру по методологии БЭМ (например, class="search-form", class="search-form__input"). Нам потом по этим классам писать CSS.

4. Доступность (Accessibility / A11y) и SEOКартинки: У всех изображений (<img>) должен быть осмысленный атрибут alt (например, alt="Вид на деревянный глэмпинг в лесу").
Интерактив: Кнопки отправки форм и открытия окон должны быть строго <button>. Ссылки для перехода — строго <a>.Скринридеры: Форма поиска должна быть понятна для незрячих. 
Используй связки <label for="..."> и <input id="...">. Кнопке закрытия или иконкам (если они будут) добавь aria-label.5. Приемка работыКод должен быть валидным и без проблем проходить проверку на сайте validator.w3.org.
