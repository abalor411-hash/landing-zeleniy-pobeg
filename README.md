# 🌲 Зелёный Побег (Green Escape)

> Семантический HTML-каркас для сервиса бронирования эко-отелей и глэмпингов.

На данном этапе проект представляет собой **эталонный HTML-скелет (без CSS/JS)**, спроектированный для максимальной SEO-оптимизации и поддержки скринридеров (Accessibility). Подготовлен для дальнейшей передачи бэкенд-разработчикам и интеграции UI-кита.

## 🌟 Особенности проекта

- **Строгая семантика HTML5:** Никакого «диватоза». Использованы смысловые теги (`<header>`, `<main>`, `<section>`, `<article>`, `<aside>`, `<footer>`).
- **Доступность (a11y):**
  - Формы связаны через `<label for="...">` и `<input id="...">`.
  - Интерактивные элементы строго разделены (`<button>` для действий, `<a>` для ссылок).
  - У всех изображений прописаны осмысленные атрибуты `alt`.
- **Архитектура БЭМ:** Все классы размечены по методологии БЭМ (Блок-Элемент-Модификатор) и полностью готовы к написанию стилей.
- **Идеальная иерархия заголовков:** Строго один `<h1>` на страницу, логичная вложенность `<h2>` и `<h3>` без пропусков.

## 🛠 Технологии

- **HTML5**
- **BEM Naming**
- **Vite** — в качестве сборщика и сервера для локальной разработки.
